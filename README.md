# omarchy-ssh-connections

Бар-виджет Omarchy (Quickshell) для быстрого доступа к SSH-подключениям,
импортированным из Tabby: кнопка в центре панели, попап с папками и поиском,
открытие в новом терминале, копирование команды, редактирование и удаление записей.

## Возможности

- **Кнопка в баре** — пилюля `SSH · N` (N = подключений с ключом на диске).
- **Попап** — папки Tabby с цветовой кодировкой (нейтральная палитра: свой цвет
  на папку — маркер и текст заголовка, левый бар и иконка строки), живой поиск
  по имени/host/user/ключу, навигация с клавиатуры.
- **Открытие** — Enter/клик: новое окно терминала по умолчанию (xdg-terminal-exec),
  команда `ssh -i <ключ> -o IdentitiesOnly=yes [-p порт] user@host`.
- **Копирование** — `C`/кнопка `copy`: ssh-команда в буфер обмена (`wl-copy`).
- **Правка и удаление** — кнопки `edit`/`del` на строке (клавиши `E`/`X`).
  Изменения хранятся отдельным слоем `overrides.json` поверх сгенерированного
  файла подключений и переживают повторный импорт из Tabby.
- **Фильтр ключей** — показываются только записи, у которых хотя бы один ключ
  реально существует на диске; мусорные пути Windows/macOS игнорируются.

## Установка

```bash
# 1. Установить (папка создастся по "id" из manifest.json, overrides.json не трогается):
./install.sh

# 2. Добавить виджет в центр бара — в ~/.config/omarchy/shell.json, секция bar.layout.center:
#    { "id": "<id из manifest.json>" }

# 3. Перезапустить шелл:
omarchy restart shell
```

Вручную — скопировать файлы плагина в
`~/.config/omarchy/plugins/<id из manifest.json>/`.

> QML-правки плагина применяются только после полного `omarchy restart shell`
> (hot-reload кэширует скомпилированный QML-файл).

## Данные

Файл подключений: `~/.config/omarchy/ssh-connections.json` — генерируется из
Tabby (`ssh-profiles-cache.json` — автоимпорт из `~/.ssh/config`; `config.yaml` —
собственные профили с папками). Пересборка — разовый скрипт.

### Формат файла подключений

```json
{
  "version": 1,
  "connections": [
    {
      "id": "0123456789abcdef",
      "name": "Example Server",
      "host": "203.0.113.10",
      "user": "root",
      "port": 22,
      "keys": ["/home/user/.ssh/id_ed25519"],
      "group": "",
      "folder": "00000000-1111-2222-3333-444455556666",
      "source": "tabby-config"
    }
  ]
}
```

- `id` — детерминированный (`sha256(name|host|user|port)[0:16]`); на нём держатся
  ручные правки (`overrides.json`) и переживают реимпорт.
- `keys` — пути ключей в порядке приоритета. Запись видна, только если хотя бы
  один unix-путь существует на диске (`~/.ssh/…`); пути Windows (`/C:\Users\…`)
  и macOS игнорируются.
- `folder` — uuid папки Tabby; имена берутся из `folderNames.json`
  (`@none` = «Без папки», `@cache` = «ssh config»).
- `source` — `tabby-config` или `tabby-cache`.

Ручные правки (`overrides.json` в каталоге плагина):

```json
{
  "deleted": ["0123456789abcdef"],
  "edits": {
    "0123456789abcdef": { "name": "Renamed", "host": "203.0.113.20", "user": "deploy", "port": 2222 }
  }
}
```

> Личные данные не входят в репозиторий: файл подключений, имена папок под свои
> uuid (`folderNames.json`) и ручные правки (`overrides.json`) живут только в
> установленном каталоге и не перезаписываются при `./install.sh`. В репозитории
> `folderNames.json` — пустой шаблон: папки без имени показываются по первым
> символам uuid до тех пор, пока не задано имя.

## Горячие клавиши в попапе

| Клавиша | Действие |
|---|---|
| `↑↓` / `jk` | движение по записям |
| `Enter` / клик | открыть в новом терминале |
| `C` / `y` | скопировать ssh-команду |
| `E` | редактировать запись |
| `X` | удалить запись (с подтверждением) |
| любой символ | поиск (фокус в поле) |
| `Esc` | закрыть / отмена |

## Структура репозитория

```
manifest.json      # id плагина, kinds: bar-widget, entryPoints.barWidget
Panel.qml          # UI: кнопка, попап, поиск, редактор, подтверждение
Connections.js     # модель (node-тестируемая): чтение файла, папки/секции,
                   # чистка имён, hueFor, поиск, overrides
folderNames.json   # uuid папок → имена, порядок секций
install.sh         # установка в ~/.config/omarchy/plugins
LICENSE
```
